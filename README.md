### 学习原则 / Principles

- **只做授权测试 / Authorized only**：代码仅用于自有环境、靶场、CTF 或明确批准的评估。
- **证据优先 / Evidence over claims**：偏好可复现命令、日志与最小证明产物。
- **防御者优先 / Defender-first**：以有助于检测、加固与回归测试的方式发布。
- **小工具、清边界 / Small tools, sharp boundaries**：避免隐藏假设、凭据泄露与不可逆操作。
